SPARK — FREE INSTALLABLE WEB APP

Files
- index.html: Spark app
- manifest.json: install/app metadata
- service-worker.js: offline cache
- icon.svg: app icon

FREE HOSTING OPTION: GitHub Pages
1. Sign in to GitHub or create a free account at github.com.
2. Create a new public repository, for example spark-planner.
3. Upload all four files from this folder to the repository root (not the ZIP file itself).
4. Open repository Settings > Pages. Under Build and deployment, select Deploy from a branch; choose main and / (root), then Save.
5. Wait for the published Pages URL shown in Settings > Pages. Open that HTTPS URL in Chrome on your Redmi phone.
6. In Chrome, open the three-dot menu and choose Install app or Add to Home screen (the wording can vary).

FREE ALTERNATIVE FOR TESTING
You can open index.html locally, but installability and offline caching generally require HTTPS or localhost. GitHub Pages provides HTTPS hosting at no cost for public repositories.

DATA AND REMINDERS
Your tasks/goals are stored in the browser's local storage on that device/browser. Export a backup from Spark Reports regularly. Do not clear browser storage unless you have a backup. Browser notifications require permission and are not guaranteed when the app/browser is closed; reliable background notifications would require additional infrastructure and are not included here.
